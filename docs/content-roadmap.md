Generated by `npm run keywords` from the two uploaded CSV exports. Numbers are copied from the files as-is. "n/a" means the CSV had no value. The export does not state which country or database the volumes come from, so confirm that in your keyword tool before relying on them. Volume and difficulty are planning hints, not predictions.

## Data notes

- `keyword-magic-800rows.csv`: 800 rows
- `keyword-magic-1000rows.csv`: 1000 rows
- 230 keywords appear in both files (values matched; merged once). 1570 unique keywords in total.
- 1472 kept as topically relevant; 98 dropped as off-topic (for example Bible verses, product model numbers, Halloween trunk-or-treat).
- 66 kept rows have a truncated SERP-features cell (shown as `+N` in the 800-row file); that column is not used.
- 0 kept rows have no difficulty value; 0 have no volume.
- Columns found: Keyword, Intent, Volume, Keyword Difficulty, CPC (USD), SERP Features. The 800-row file writes volume with thousands separators and abbreviates intent (I, C).

## Notes

- Pair each new post with one primary keyword and a few close variants. Write for the reader first; do not stuff keywords.
- Several head terms are the Crock-Pot trademark. Describing a slow cooker generically ("slow cooker") is safer for brand copy than relying on the trademark.
